# 🚀 3W Social Feed

A modern full-stack social media application built using React.js, Node.js, Express.js and JWT Authentication.

Users can create accounts, share posts, upload images through URLs, like posts, comment on posts, bookmark posts, edit their own posts, delete posts, search content, and switch between light and dark mode.

# ⚙️ Installation

## Backend Setup

```bash
cd backend

npm install

npm run dev
```

Backend runs on:

```bash
http://localhost:5000
```

---

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```
