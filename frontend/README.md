# 🚀 3W Social Feed

A modern social media web application built for the 3W Full Stack Internship Assignment.

Users can create accounts, share posts, upload images using URLs, like posts, comment on posts, search content, switch between light and dark mode, and interact through a clean social feed interface.

---

## 📸 Features

### Authentication
- User Signup
- User Login
- JWT Authentication
- Protected Routes
- Persistent Login Session

### Social Feed
- Create Text Posts
- Create Image Posts
- Public Feed
- Real-Time Feed Updates
- Post Timestamp

### Engagement
- Like Posts
- Comment on Posts
- View Total Likes
- View Total Comments
- Display Usernames of People Who Liked
- Display Usernames of People Who Commented

### UI Features
- Modern Instagram Inspired Layout
- Responsive Design
- Dark Mode
- Search Posts
- Profile Sidebar
- User Profile Drawer
- Quick Statistics Panel
- Trending Section
- Clean and Professional Design

---

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router DOM
- Axios
- CSS3

### Backend
- Node.js
- Express.js
- JWT Authentication
- bcryptjs

### Database
- LowDB (Development Storage)

> The project architecture is designed in a way that MongoDB Atlas can be integrated easily by replacing the storage layer without changing API routes.

## ⚙️ Installation

### Clone Repository

```bash
git clone <your-github-repository-link>
```

### Backend Setup

```bash
cd backend

npm install

npm run dev
```

Backend runs on:

```bash
http://localhost:5000
```

---

### Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```
